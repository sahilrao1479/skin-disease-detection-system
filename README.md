\# Skin Disease Detection System



\## Overview

This project is a CNN-based skin disease detection system developed using MobileNetV2, Flask, and SQLite. The system allows doctors to securely log in, upload dermatoscopic skin images, and receive predicted skin diseases with confidence scores.



\---



\## Features

\- Doctor Login \& Registration

\- CNN-based Disease Classification

\- MobileNetV2 Transfer Learning

\- Top 2 Disease Predictions

\- Non-Skin Image Detection

\- Flask Backend Integration

\- SQLite Database Authentication

\- Responsive Web Interface



\---



\## Technologies Used

\- Python

\- TensorFlow / Keras

\- Flask

\- SQLite

\- HTML/CSS/JavaScript

\- MobileNetV2
